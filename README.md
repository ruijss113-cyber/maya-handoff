# הורדת דוחות כספיים מאתר מאיה (TASE)

חבילה עצמאית להורדה מרוכזת של דוחות כספיים רבעוניים ושנתיים
מאתר מאיה של הבורסה לניירות ערך בתל אביב.

---

## 1. התקנה

נדרש **Python 3.10 ומעלה** (נבדק על 3.13.5).

```bash
pip install -r requirements.txt
```

**חשוב ב-Windows** — לפני כל הרצה, כדי שהפלט בעברית לא יישבר:

```powershell
$env:PYTHONIOENCODING = "utf-8"
python -u maya_bulk_downloader.py ...
```

(ה-`-u` חשוב כדי לראות התקדמות בזמן אמת ולא בסוף.)

---

## 2. הדבר הכי חשוב לדעת: למה הקוד הפשוט מחזיר 403

`maya.tase.co.il` יושב מאחורי **Imperva WAF**. קריאה ישירה ל-API
מחזירה `HTTP 403` עם דף HTML, גם אם הכתובת נכונה לחלוטין.

כדי לעבור צריך **שני דברים יחד**:

1. **User-Agent של דפדפן.** ברירת המחדל `python-requests/2.x` נחסמת.
2. **לבקר קודם ב-`https://maya.tase.co.il/he`** בשביל לאסוף את עוגיות
   ה-Imperva (`visid_incap_119455`, `incap_ses_1051_119455`), ורק אז
   לקרוא ל-API באותו `requests.Session`.

כותרות נוספות (`Referer`, `Origin`, `Sec-Fetch-*`, `sec-ch-ua`) לא
משנות כלום — נבדק.

> `mayafiles.tase.co.il` (שרת קבצי ה-PDF) **אינו** מאחורי ה-WAF
> ועובד עם User-Agent בלבד.

כל זה כבר ממומש ב-`build_session()` וב-`warm_up()` בתוך
`maya_bulk_downloader.py`, כולל רענון עוגיות אוטומטי כשמקבלים 403
באמצע ריצה. **אין צורך לעשות כלום** — רק אל תחליף את ה-session.

## 3. מגבלות שרת שחייבים להכיר

| מגבלה | ערך |
|---|---|
| `pageSize` | **1–30 בלבד.** 50 או 100 מחזירים HTTP 400. חובה לעמד (pagination). |
| `fromYear` | **חייב להיות 2000 ומעלה.** |
| `period` | `1`=Q1, `2`=Q2, `3`=Q3, `4`=שנתי |
| רבעון 4 | **לא קיים.** הדוח השנתי מכסה אותו. |
| `by` | חייב להיות `"company"` יחד עם `companyId`. בלי `by` מוחזרת רשימה ריקה. |
| `companyIds` (ברבים) | מחזיר 403. רק `companyId` ביחיד. |
| `/api/v1/reports/{id}` | מחזיר **403** גם עם session חם. אל תסתמך עליו. |

**מספר מנפיק בורסה = `companyId` ב-API.** (לא `corporateNo` — זה
מספר רשם החברות, מספר אחר לגמרי.)

## 4. בניית כתובת ה-PDF — כאן היה באג אמיתי

קבצי ה-PDF יושבים בתיקיות של 1000 לפי **טווחים סגורים**:
`1..1000`, `1001..2000`, `2001..3000`...

כלומר מזהה שמתחלק ב-1000 (למשל `987000`) שייך לתיקייה
**הקודמת**, לא הבאה:

```python
# נכון:
start = ((int(rid) - 1) // 1000) * 1000 + 1
url = f"https://mayafiles.tase.co.il/rpdf/{start}-{start+999}/P{rid}-00.pdf"

# שגוי (הנוסחה המקורית) - מפספס כל מזהה שמתחלק ב-1000:
# start = (int(rid) // 1000) * 1000 + 1
```

תגובת 404 מגיעה עם `content-type: text/html` ו-`content-length: 1245`,
ולכן **חובה לבדוק את ה-magic bytes `%PDF-`** ולא רק את קוד הסטטוס.

הסיומת היא תמיד `-00`. אין `-01` / `-02`.

## 5. הבעיה הכי מסוכנת: מצגות במקום דוחות

ה-API מחזיר לכל פריט רק: `id`, `publishDate`, `companyId`,
`companyName`, `companyType`, `tradeHaltMessage`, `tradeHaltTypeName`,
`period`, `year`.

**אין שדה כותרת או נושא.**

הבעיה: באותו (שנה, רבעון) מאיה מפרסמת לפעמים כמה פריטים —
הדוח הכספי האמיתי, מצגת למשקיעים, תיקון טכני, או הודעת
חידוש מסחר ללא PDF בכלל. בחירה לפי "הפרסום החדש ביותר"
תופסת את המצגת.

דוגמאות אמיתיות שנתפסו:
* `1230000` = 11 עמודים (מצגת לשוק ההון) מול `1229998` = **84 עמודים** (הדוח).
* `734000` = 4 עמודים (תיקון) מול `726106` = **313 עמודים** (הדוח השנתי).

במחזור הראשון: **1,206 מתוך 5,192 הסלוטים** היו עם יותר ממועמד אחד,
ו-**456 קבצים הוחלפו** אחרי בדיקה.

**ההבחנה היחידה האמינה היא מספר העמודים בפועל** — צריך להוריד ולספור.
מצגות הן בד"כ 4–27 עמודים, דוחות אמיתיים 45–450.

לכן: **תמיד להריץ את `maya_quality_check.py` אחרי כל הורדה.**
הסקריפט הראשי כבר מנסה את כל המועמדים לפי סדר (כדי לדלג על הודעות
בלי PDF), אבל הוא לא סופר עמודים תוך כדי — זה תפקיד שלב הבדיקה.

## 6. איך מריצים

### שלב א' — הורדה

```powershell
$env:PYTHONIOENCODING = "utf-8"
python -u maya_bulk_downloader.py --excel "inputs\batch2_input.xlsx" --out "D:\maya_reports" *> download.log
```

דגלים:

| דגל | משמעות |
|---|---|
| `--excel` | קובץ הקלט (ראה פורמט למטה) |
| `--out` | תיקיית יעד |
| `--dry-run` | רק מראה מה היה יורד, בלי להוריד |
| `--only` | מספרי מנפיק **מופרדים בפסיק** (לא ברווח!), למשל `--only 1724,434` |
| `--limit` | מגביל את מספר הדוחות לחברה — לבדיקות |

**ההרצה מתחדשת (resumable).** הדילוג מבוסס על קיום הקובץ בדיסק,
לכן אפשר לעצור באמצע ולהריץ שוב — הוא ימשיך מאיפה שהפסיק.

### שלב ב' — בדיקת איכות (אל תדלג על זה)

```powershell
python -u maya_quality_check.py --root "D:\maya_reports"
```

* `--mode suspicious` (ברירת מחדל) — בודק רק קבצים חריגים: פחות מ-25
  עמודים, או פחות מחצי מהחציון של אותה חברה. מהיר.
* `--mode all` — בודק כל סלוט מול ה-API. **הרבה יותר איטי** אבל יסודי.
  מומלץ להרצה ראשונה של אצווה גדולה.
* `--dry-run` — מראה מה היה מוחלף בלי לגעת בקבצים.

מפיק `_quality_report.csv` עם כל ההחלפות.

### שלב ג' — ארגון לתיקיות

```powershell
# שתי תצוגות מקבילות: "לפי רבעון" ו-"לפי חברה"
python -u build_both_views.py --root "D:\maya_reports" --excel "inputs\batch2_input.xlsx"

# או רק חלוקה לרבעונים:
python -u reorg_by_quarter.py --root "D:\maya_reports"
```

`build_both_views.py` **מעביר** ל-`לפי רבעון\<שנה> <רבעון>\` ואז
**מעתיק** ל-`לפי חברה\<פילוח>\<מנפיק> - <שם>\`. כלומר נפח הדיסק
מוכפל. אם אין מקום — השתמש ב-`reorg_by_quarter.py` בלבד.

## 7. פורמט קובץ הקלט

קובץ Excel, **גיליון ראשון, שורת כותרת אחת**, חמש עמודות לפי הסדר:

| פילוח | מספר מנפיק | שם החברה | תקופה ראשונה | תקופה אחרונה |
|---|---|---|---|---|
| נדל"ן ובינוי | 1724 | רמות בעיר בע"מ | Q1 2026 | Q2 2026 |
| נדל"ן מניב | 323 | מליסרון בע"מ | Q1 2010 | Q2 2026 |

* שמות העמודות לא משנים — הקוד קורא לפי **מיקום**.
* תאי התקופה נקראים ע"י `parse_period_cell()` ותומכים ב-`Q1 2026`,
  `2026 Q1`, `רבעון 1 2026` וכד'.
* **הטווח כולל גם דוחות שנתיים** — `Q1 2010` עד `Q2 2026` מייצר את כל
  הרבעונים והשנתיים שביניהם.
* שורות עם תקופות שלא נפרסו מדווחות בקונסול ומדולגות.

ב-`inputs\` נמצאים שני קבצי קלט מוכנים:
* `batch1_input.xlsx` — 129 חברות נדל"ן מניב, טווחים מלאים (כבר הורד).
* `batch2_input.xlsx` — 86 חברות נדל"ן ובינוי, Q1+Q2 2026 בלבד (כבר הורד).

## 10. תקלות נפוצות

| תסמין | סיבה / פתרון |
|---|---|
| `HTTP 403` על כל קריאת API | לא בוצע warm-up, או User-Agent לא של דפדפן. הקוד מטפל בזה אוטומטית — ודא שאתה לא בונה session משלך. |
| `403` חוזר באמצע ריצה ארוכה | תקין. הקוד מרענן עוגיות עד 4 פעמים ומנסה שוב. |
| `HTTP 400` עם `'Page Size' חייב להיות בין 1 לבין 30` | מישהו שינה את `pageSize`. החזר ל-30. |
| קבצים של 1,245 בתים | זה דף 404 של השרת, לא PDF. בדיקת ה-`%PDF-` אמורה לתפוס את זה. |
| קבצים קטנים מדי / 4–11 עמודים | מצגת משקיעים או תיקון. הרץ `maya_quality_check.py`. |
| פלט עברית שבור בקונסול | `$env:PYTHONIOENCODING = "utf-8"` |
| `ModuleNotFoundError` אחרי שיצרת `inspect.py` | **אל תקרא לסקריפט זמני `inspect.py`** — זה מסתיר מודול מהספרייה התקנית ושובר את numpy/pandas. |
| הורדה לתיקייה שמסונכרנת ל-OneDrive נתקעת | OneDrive מוגבל ל-5 GB בחשבון חינמי. שים לב ש-Desktop/Documents ב-Windows מופנים ל-OneDrive כברירת מחדל. הורד לכונן רגיל. |
| קריאה מכונן Google Drive (`G:`) איטית מאוד | Drive מושך מהענן בכל קריאה. אל תסרוק PDF-ים מחדש מ-`G:` — השתמש ב-`batch1_inventory.csv` כמטמון. |
| Google Drive מציג רק ~45 תיקיות מתוך 129 | זה lazy-loading בממשק הווב. הקבצים קיימים. גלול, או בדוק דרך הקליינט. |

## 12. שיקול משפטי

דוחות מאיה הם פרסומי חובה ציבוריים לפי דיני ניירות ערך בישראל,
אבל לאתר מאיה יש תנאי שימוש. **שכפול מרוכז של אלפי קבצים במאגר
ציבורי** (GitHub ציבורי, אתר, וכו') הוא חשיפה שכדאי להימנע ממנה.
לשימוש פנימי/מחקרי — שמור את זה פרטי.
